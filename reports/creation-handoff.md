- **Validated advantage:** the current deterministic suite covers native builds, connector types, separate ports, content/print budgets, changed or invented evidence, overwrite refusal, and failed-build cleanup. Existing accepted vectors and the official/relay image adapter remain unchanged.
- **Hypothesis:** this workflow will improve other paper-to-diagram tasks. One selected primary-paper example and an agent review do not establish broad scientific performance or independent validation.

This update follows skill-creator's focused resources and meaningful runtime checks. Earlier reference skills and candidate-specific lessons remain documented in the historical handoff below and the prior-art report. Original contributions in 0.4.0 are source-extract integrity checks, an explicit native methodology builder, physical-size/content-budget checks, distinguishable connector symbols and ports, and an attributed primary-paper example. ## Historical 0.2.0 handoff

Local preview, English package, unchanged invocation `daxuan-science-assets`. This update addresses two observed failures: diagnosing a relay with an OAuth-only check, and presenting a white gallery instead of an individual transparent asset.

- **Design advantage:** choose drawing method independently of source. Native SVG is sufficient for simple supported structures and exact edits; requested image exploration uses the active official or relay source.
- **Validated advantage:** the active relay source was selected from Codex config and a real `gpt-image-2` request saved a PNG after HTTP 200. The reference is opaque RGB; a separate native render provides verified transparent RGBA.
- **Validated advantage:** source, origin-bound credentials, no-retry behavior, PNG alpha and existing vector tools pass the current unit suite. Three original SVG/PNG fixtures, palettes and both legacy core tools remain unchanged against the frozen baseline.
- **Hypothesis:** this explicit routing will reduce setup failures on other users' official/relay configurations. No universal provider compatibility or scientific-art superiority is claimed.

References studied: Daxuan Image Relay supplied lessons about separating Responses from Images, explicit API bases, authenticated protected downloads and actual alpha checks. Its fixed preferred relay and automatic generation retries were deliberately not adopted. The optional Codex GPT Image helper remains the official OAuth dependency. Earlier ScanSci SVG and schematic-figure lessons about editing existing vectors and inspecting real renders remain in the [prior-art report](prior-art-research.md).

Original contributions in this update are the selected-source router, credential-origin boundary, evidence levels, one-request adapter, and direct single-asset handoff contract. No credentials or authentication implementation were copied into examples.
