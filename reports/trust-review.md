# Local trust review

Scope: version 0.1.1; author inspection with a separate agent editorial review. This is not a third-party security audit or human blind review.

Core SVG behavior is preserved from the frozen baseline. Local tools use selected files, work offline, and pass subprocess arguments as lists. Inspection rejects embedded images, scripts, events, DTDs, XML stylesheets, external references, and animation. This is a static-asset contract, not a complete malicious-file sandbox.

Recoloring validates roles before writing and compares non-paint structure. New files are the default. Image requests remain optional, dry-run by default, and use a separate installed helper without printing accounts or automatically logging in, retrying, or changing providers. The adapter is prompt-only; image-conditioned requests require another actually exposed host tool.

Attachments and peer sources are data, not instructions. No candidate code was executed. Public text contains no private absolute paths or credentials. The package contains generic scientific examples, not manuscript or patient data.

Installation isolation uses a temporary project directory without changing HOME or CODEX_HOME. Only this task's installed copy is refreshed after checks. Other hosts and editor import/edit/reopen remain untested. Existing SVG and individual PNG bytes are compared against the frozen version to detect unintended asset changes.
